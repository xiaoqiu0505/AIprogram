# SolidWorks 零件生成器

用 AI 把一个想法，变成一个真实的三维零件。

---

## 这是什么

一个 Windows 桌面程序。你给它一张零件图片，或者一段文字描述，它会：

1. 调用 DeepSeek AI（多模态 + 深度思考）理解你要什么零件
2. 规划出完整的建模步骤（拉伸、切除、圆角、倒角……）
3. 自动驱动本机的 SolidWorks 完成建模
4. 把零件文件 `.SLDPRT` 保存到你的「下载」文件夹

**你不需要懂 SolidWorks 的操作。**

## 快速开始

### 1. 准备

- Windows 10 / 11
- 电脑上已安装 **SolidWorks**（2020 及以上，本程序在 2026 SP4.1 上验证）
- 一个 **DeepSeek API Key**（在 [platform.deepseek.com](https://platform.deepseek.com) 申请）

### 2. 运行

双击 `dist\SolidWorks零件生成器.exe`

> 首次启动约需 5~10 秒（单文件模式需要解压），之后会快一些。

### 2.5 上传图片的方式

**方式一：点击选择**
点「① 上传零件图片」的框 → 选文件。

**方式二：拖拽（更快）**
从资源管理器把图片**直接拖进**那个框就行。

- 拖 **1 张**：普通图片预览
- 拖 **3 张**：自动按三视图处理（标注 主视图/侧视图/俯视图）
- 拖 **2 张**：按「图1 / 图2」预览
- 非图片文件会被自动过滤，不会出错

**多张图片是累加的**：先拖 1 张，再拖 2 张 → 一共 3 张，不会覆盖。
每张预览图右上角有红色「**×**」，点它就能单独删掉这张。

### 2.6 「预备输入」面板

设计页右侧有个 **「📋 预备输入」** 面板，实时显示你准备发送给 AI 的内容：

`
📋 预备输入                    3 张图 + 1 段文字
  🖼 主视图：cup_front.png
  🖼 侧视图：cup_side.png
  🖼 俯视图：cup_top.png
  ✏ 文字：一个带 Φ30 通孔的方块
  ▸ 将按三视图发送给 AI
`

它跟着你的操作自动更新：

| 操作 | 面板变化 |
|---|---|
| 上传/拖入图片 | 增加对应条目 |
| 点 × 删除某张 | 对应条目消失 |
| 清空图片 | 图片条目全部消失 |
| 输入文字 | 出现「✏ 文字：…」条目 |
| 建模完成 | 全部清空（显示「无」） |

**这样你能随时确认"到底会发什么给 AI"**，避免删了图但旧数据还在的混乱。

> 支持格式：JPG / PNG / WebP / BMP / GIF，单张不超过 30MB。

## 手绘草图功能

点击「✏ **手绘一个3D草图，尽情绘制吧**」，会弹出一个大画布窗口。

> PS：简单零件手绘更好识别，复杂零件建议用图片或文字。

### 两种绘制模式

#### 模式一：自由绘制（默认）

一个画布随便画，点「画好了！」导出**一张**图片给 AI。

适合：形状简单、一眼能看懂的零件。

#### 模式二：三视图模式（推荐，精度更高）

点左下角 **「⊞ 三视图模式」** 进入。三视图能完整表达零件的三维形状，
AI 识别的成功率明显高于单张自由草图。

进入后界面变化：

| 位置 | 内容 |
|---|---|
| **左上角** | 当前视图名称 + **立体直角坐标系**（随视图变化） |
| **画布上方** | 主视图 / 侧视图 / 俯视图 **三个切换按钮** + 「当前：xxx」 |
| **画布** | 当前视图的绘图区（各视图的笔迹**互相独立保存**） |

**坐标系随视图变化**：

| 视图 | 观察方向 | 坐标轴显示 |
|---|---|---|
| 主视图 | 从正面看 | X 向右（红）、Y 向上（绿）、Z 斜向外（蓝） |
| 侧视图 | 从左侧看 | Z 向右、Y 向上、X 斜向外 |
| 俯视图 | 从上方看 | X 向右、Z 向下、Y 斜向外 |

**画笔工具**（工具栏第二行）：

| 工具 | 说明 |
|---|---|
| **颜色** | 黑 / 红 / 蓝 / 绿四个色块，点击切换（画笔、多边形、填充都用它） |
| **粗细** | 滑杆拖动，1~30 px（滚轮也能调） |
| **✏ 画笔** | 按住左键拖动，随手画 |
| **⬠ 多边形** | 先选形状（△三角 / ▭矩形 / ⬠五边 / ⬡六边 / ★星形），再按住左键**拖拽拉伸**，松开完成 |
| **🪣 填充** | 点任意**闭合区域内部**填充；或用「**⚡ 填充全部闭合区域**」一次性填满所有区域 |
| **⊞ 文字** | 点画布任意位置 → 输入文字 → **回车**确认（Esc 取消） |

> **多边形怎么用**：切到「⬠ 多边形」→ 右侧出现形状选择器 →
> 点一个形状（如「▭ 矩形」）→ 在画布上**按住左键拖拽**出想要的大小 →
> **松开左键**就画好了。拖拽时会实时显示预览和尺寸。
>
> **填充怎么用**：先用画笔或多边形画一个**闭合轮廓**，然后切到「🪣 填充」，
> 点轮廓内部即可上色。不同区域可以填不同颜色。
> 填充是按洪水算法算的，红色线条会被当作边界，颜色不会漏出去。

> **红色 = 贯穿**：三视图模式下，想表示零件"透过去"（通孔、通槽），
> 用**红色**画。AI 会据颜色判断该特征要用 	hrough_all 贯穿切除。
> 左栏和工具栏都有「贯穿部分用红色标注」的提醒。

**使用流程**：

1. 进入三视图模式，默认在「主视图」
2. 画主视图 → 点「侧视图」→ 画侧视图 → 点「俯视图」→ 画俯视图
3. 切换视图时，**之前画的笔迹会自动保存**，切回来还在
4. 如果点的是当前视图，会提示「**这个视图就是！**」
5. 三个视图都画完 → 点「**画好了！**」
6. 程序会**一次性把三张图**（主视图、侧视图、俯视图）发给 AI，
   每张图**右下角自动标注视图名**，AI 能直接对上
7. AI 会按「长对正、高平齐、宽相等」的制图规则推断三维形状

> 三个视图必须**都画完**才能导出，缺哪个会提示你。

### 画布操作

| 操作 | 效果 |
|---|---|
| **按住左键拖动** | 绘制黑色笔迹 |
| **松开左键** | 提笔（结束当前笔画） |
| **滚轮上下** | 调整笔的粗细（1~60 px） |
| **F11** | 全屏 / 退出全屏 |
| **Esc** | 退出全屏 |
| **Ctrl+Z** | 撤销上一笔 |
| **拖边框** | 自由缩放窗口大小 |

窗口右上角有「**画好了！**」按钮：
- 点击后自动把画布内容转成临时 PNG
- 图片会塞进设计页的图片框作为预览
- 之后点「开始设计」，这张图会作为**手绘草图**发给 AI
- 此时提示词自动切换为：`这是一个用户手绘的 3D 草图，依据它来生成 solidworks 文件`

### 导出原理

画布导出用 **Pillow 按笔迹重绘**，不是屏幕截图。好处：

- 只有笔迹，白底黑线，不会被其他窗口遮挡污染
- 自动裁剪多余空白，图片更紧凑
- 不需要窗口在最前面，后台也能正确导出

## 3D 打印导出

设计页右侧有「**🖨 导出3D打印文件**」按钮：

| 状态 | 说明 |
|---|---|
| 灰色不可点 | 还没生成零件 |
| 蓝色可点 | 建模成功后自动激活 |

点击后会：

1. 重新连接 SolidWorks，打开刚才的零件
2. 以**精细质量**导出 STL（二进制格式，适合 3D 打印）
3. 保存到与 `.SLDPRT` **完全相同的目录**
4. 完成后自动打开文件夹

STL 可以直接拖进任何切片软件：Cura、PrusaSlicer、Bambu Studio、OrcaSlicer……

### 导出参数

| 参数 | 值 |
|---|---|
| 格式 | 二进制 STL |
| 质量 | Fine（精细） |
| 弦高偏差 | 0.05 mm |
| 角度公差 | 10° |
| 单位 | 毫米 |

## 支持的零件类型

程序背后是一个「特征级」的建模引擎。AI 负责把你的需求翻译成建模步骤，
引擎负责真正驱动 SolidWorks 执行。

### 六种特征

| 特征 | 用途 | 典型零件 |
|---|---|---|
| `extrude` 拉伸凸台 | 加材料 | 方块、板件、法兰 |
| `cut` 拉伸切除 | 减材料 | 打孔、挖槽 |
| `revolve` 旋转 | **回转体** | 杯子、瓶子、圆锥、圆柱、轮子、轴 |
| `shell` 抽壳 | 挖成薄壁腔 | 杯子内腔、盒子、容器 |
| `fillet` 圆角 | 修饰 | 去锐边、减小应力集中 |
| `chamfer` 倒角 | 修饰 | 装配导向、去毛刺 |

### 建模公式

大部分零件都是这几个特征的组合：

```
圆柱 / 圆锥 / 圆台     = revolve
杯子 / 碗 / 容器       = revolve + shell
六角螺母               = extrude(polygon) + chamfer + cut
法兰盘                 = revolve + cut(圆周孔)
带孔方板               = extrude + cut
```

### 旋转体的坐标约定

`revolve` 的 `profile` 是剖面点位，**x = 半径，y = 高度**，绕 Y 轴旋转：

```json
{
  "type": "revolve",
  "profile": [[0,0], [50,0], [35,85], [0,85]],
  "angle": 360
}
```

含义：
- `[0,0]` 底部中心
- `[50,0]` 底部半径 50 → **底径 100**
- `[35,85]` 顶部半径 35 → **口径 70**
- `[0,85]` 顶部中心
- 结果：一个上小下大的实心圆锥台，高 85

加 `shell` 就变成杯子：

```json
{"type": "shell", "thickness": 3, "remove_faces": "top"}
```

### 坐标系说明

| 方向 | 含义 |
|---|---|
| **Y** | 高度（旋转轴方向） |
| X / Z | 直径方向 |

> 抽壳选「顶面」时按 Y 轴判断最高面，这是引擎内部处理的细节。

## 输入示例

### 内置范例（推荐）

设计页「② 用文字描述」标题右侧有个 **「📖 查看范例」** 按钮，点开是个独立窗口，
内置 **9 个零件范例**，按类别分好：

| 分类 | 范例 |
|---|---|
| 标准件 | 六角螺母 M10、垫圈 |
| 回转体 | 带把手水杯、阶梯轴、圆盘 / 碗 |
| 盘类 | 法兰盘 |
| 基础 | 带孔方块、圆柱销 |
| 组合 | 轴承座 |

**点任意一个范例**（或它右边的「使用 →」按钮），文字会自动填进描述框，
然后可以直接开始设计，也可以基于它改尺寸。

### 文字描述示例

```
一个 M10 六角螺母，对边宽度 16mm，厚度 8mm，
中心是 M10 螺纹孔（底孔 8.5mm），六条棱边倒角 C1。
```

```
设计一个法兰盘：外径 120mm，内径 40mm，厚度 15mm，
沿圆周均匀分布 6 个 φ10mm 的通孔，中心有一个 φ40mm 的通孔。
```

```
一个阶梯轴，小端 φ25 长 50mm，大端 φ40 长 30mm，
台阶处圆角 R2，两端倒角 C1.5。
```

### 描述技巧

- **给出具体尺寸**（直径、长度、厚度）比只描述形状效果好
- 涉及标准件时说清标准（如「GB/T 6170 M10 六角螺母」）
- 回转体（杯、瓶、盘）说明上口直径、底部直径、高度、壁厚
- 有孔的话说明孔径和分布

### 图片输入建议

- 用**清晰的照片或截图**，零件轮廓要能看清
- 工业零件的三视图、实物照片效果都不错
- 图片会自动压缩到合理大小（不占太多 token）
- 手绘草图也行（点「✏ 手绘一个3D草图」，简单零件效果更好）

## API Key 说明

- **保存在哪**：`%APPDATA%\SolidWorksPartGen\config.json`，结构如下：

```json
{
  "keys": {
    "deepseek": {"api_key": "sk-...", "verified": true, "verified_fingerprint": "..."},
    "qwen":     {"api_key": "sk-...", "verified": true, "verified_fingerprint": "..."},
    "kimi":     {"api_key": "sk-...", "verified": false, "verified_fingerprint": ""},
    "chatgpt":  {"api_key": "sk-...", "verified": false, "verified_fingerprint": ""},
    "claude":   {"api_key": "sk-ant-...", "verified": true, "verified_fingerprint": "..."}
  },
  "active_provider": "deepseek"
}
```

- **会重新校验吗**：每家独立判断。只有**换 Key** 或**换服务商**时才重新校验；
  同一个 Key 通过后不再重复校验（用 SHA256 指纹比对，不存明文索引）
- **怎么更换**：在右上角对应服务商的输入框里改，点「存」即可
- **怎么切换服务商**：下方「使用」下拉框选择
- **安全**：所有 Key 都只存在本地文件里，不会上传到任何第三方服务器；

## 源码说明

### `src/app.py` — 界面与流程控制

三层页面结构：

```
App (主窗口)
 ├── 顶栏：API Key 输入 + 状态显示
 ├── HomePage      → 主页，入口
 ├── ChoicePage    → 选择身份
 └── DesignPage    → 零件设计（主工作区）
```

关键逻辑：

| 方法 | 作用 |
|---|---|
| `App.on_save_key()` | 保存 Key，Key 变了就清空验证状态 |
| `App.check_key_and_go()` | 校验 Key，通过才进设计页，失败退回主页 |
| `DesignPage.start_design()` | 启动后台线程：AI 分析 → 建模 → 保存 |
| `DesignPage._worker()` | 后台工作线程（避免界面卡死） |

> 所有耗时操作都在子线程里跑，主线程只负责刷新 UI。

### `src/sketchpad.py` — 手绘草图画布

| 类/方法 | 作用 |
|---|---|
| `SketchPad(parent, on_done)` | 画布窗口，`on_done(path)` 在点「画好了！」后回调 |
| `_on_press/_on_drag/_on_release` | 鼠标绘制三件套，记录笔迹到 `self.strokes` |
| `_on_wheel` | 滚轮改 `brush_size`（1~60） |
| `_toggle_fullscreen` | F11 全屏切换 |
| `undo` / `clear_all` | 撤销 / 清空 |
| `finish` | 导出 PNG 并回调 |
| `_export_canvas` | 用 Pillow 按 strokes 重绘成 PNG |

导出不依赖屏幕截图，而是按记录的笔迹重绘：

```python
img = Image.new("RGB", (cw, ch), (255, 255, 255))
draw = ImageDraw.Draw(img)
for stroke in self.strokes:
    draw.line(stroke, fill=(0, 0, 0), width=self.brush_size, joint="curve")
```

好处：只有笔迹不会抓到其他窗口、自动裁剪空白、后台也能导出。

### `src/api_client.py` — 多服务商 AI 接口

| 函数 | 作用 |
|---|---|
| `verify_key(key, provider)` | 校验指定服务商的 Key |
| `analyze_part(key, text, image, is_sketch, provider, image_paths, is_three_view)` | 多模态分析（支持单图/三视图），返回建模 JSON |
| `_build_verify_request(provider, key)` | 构造校验请求（各家格式不同） |
| `_build_analyze_request(...)` | 构造分析请求 |
| `_extract_answer(provider, data)` | 从各家响应中取文本 |

#### 两类的请求差异

**DeepSeek / ChatGPT**（OpenAI 兼容）：

```python
url = f"{base_url}/chat/completions"
headers = {"Authorization": f"Bearer {key}"}
payload = {
    "model": "...",
    "messages": [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": [图像块, 文字块]},
    ],
}
# DeepSeek 额外开深度思考
payload["thinking"] = {"type": "enabled"}
payload["reasoning_effort"] = "high"
```

图片块（两者相同）：

```python
{"type": "image_url",
 "image_url": {"url": "data:image/jpeg;base64,...", "detail": "high"}}
```

**Claude**（Anthropic Messages API）：

```python
url = f"{base_url}/v1/messages"
headers = {
    "x-api-key": key,                          # 不是 Bearer
    "anthropic-version": "2023-06-01",         # 必须有
    "content-type": "application/json",
}
payload = {
    "model": "claude-sonnet-4-5-20250929",
    "max_tokens": 8000,
    "system": SYSTEM_PROMPT,                   # system 独立字段
    "messages": [{"role": "user", "content": [图像块, 文字块]}],
}
```

图片块（Claude 格式不同）：

```python
{"type": "image",
 "source": {"type": "base64", "media_type": "image/jpeg", "data": "..."}}
```

响应解析也不同：

| 服务商 | 取文本 | 取思考 |
|---|---|---|
| DeepSeek | `choices[0].message.content` | `message.reasoning_content` |
| ChatGPT | `choices[0].message.content` | — |
| Claude | `content[] 中 type=="text" 的块` | `type=="thinking"` 的块 |

**AI 返回的 JSON 结构**（System Prompt 里约束死的）：

```json
{
  "part_name": "六角螺母M10",
  "part_name_en": "hex_nut_m10",
  "summary": "GB/T 6170 M10 六角螺母",
  "material": "8级碳钢",
  "features": [
    {"type": "extrude", "sketch": {"plane": "front", "shape": "polygon",
     "params": {"sides": 6, "across_flats": 16}}, "depth": 8},
    {"type": "chamfer", "distance": 1, "target": "vertical_edges"},
    {"type": "cut", "sketch": {"plane": "top", "shape": "circle",
     "params": {"radius": 4.25}}, "direction": "through_all"}
  ],
  "dimensions": [{"name": "对边宽度", "value": 16, "unit": "mm"}],
  "notes": "设计说明"
}
```

支持的特征类型：

| type | 参数 | 说明 |
|---|---|---|
| `extrude` | sketch, depth, direction | 拉伸凸台 |
| `cut` | sketch, depth, direction | 拉伸切除 |
| `fillet` | radius, target | 圆角 |
| `chamfer` | distance, angle, target | 倒角 |

草图形状（`sketch.shape`）：

| shape | 参数 |
|---|---|
| `rectangle` | width, height, center_x, center_y |
| `circle` | radius, center_x, center_y |
| `polygon` | sides, circumradius 或 across_flats, start_angle |
| `profile` | profile: [[x,y], ...] 自定义轮廓 |

### `src/sw_builder.py` — SolidWorks 建模核心

#### STL 导出（`export_stl`）

```python
# 设置 STL 导出参数
self.sw.SetUserPreferenceIntegerValue(78, 2)      # swSTLQuality = Fine
self.sw.SetUserPreferenceToggle(69, True)         # 二进制格式
self.sw.SetUserPreferenceDoubleValue(2, 0.05)     # 弦高偏差 0.05mm
self.sw.SetUserPreferenceDoubleValue(3, 10.0)     # 角度公差 10°
self.doc.SaveAs3(stl_path, 0, 1)                  # 静默保存
```

实测：50mm 立方体导出 STL 为 684 字节、12 个三角形，文件头校验完整。

这是整个项目技术难度最高的部分。踩过的坑都写在注释里了：

#### 坑 1：COM 必须用静态绑定

用 `win32com.client.dynamic.Dispatch`（晚绑定）时，所有特征创建 API 都会报
「非选择性的参数」。必须用 `makepy` 生成静态绑定：

```python
lib = pythoncom.LoadTypeLib(tlb_path)
gi, lcid, _sk, major, minor, _fl = lib.GetLibAttr()
spec = (str(gi), lcid, major, minor)     # ⚠ 必须是 4 元组，5 元组会失败
makepy.GenerateFromTypeLibSpec(spec)
```

#### 坑 2：`FeatureExtrusion3` 要 23 个参数

少传会报「类型不匹配，参数 21」。完整参数见源码 `_add_extrude()`。

#### 坑 3：选边/选面要用原始 CDispatch

```python
# ✗ 错误：静态包装后的 IEdge 没有 Select 方法
edge = mod.IEdge(raw._oleobj_)
edge.Select(True)

# ✓ 正确：用原始 CDispatch
raw.Select(True)
```

#### 坑 4：切除方向

草图在上视/右视基准面时，单向「完全贯穿」可能只切一半。
本程序在 `cut + through_all` 时自动改用**两侧对称**（`sd_flag = False`）。

#### 坑 5：`SaveAs` 卡死

`doc.Save()` 在文档未命名时会弹出「另存为」对话框并阻塞。
必须用 `doc.SaveAs3(path, 0, 1)`，最后的 `1` 是 `swSaveAsOptions_Silent`。

## 常见问题

### Q: 启动后一闪就没了？

用命令行运行看错误：

```cmd
"D:\New Program\dist\SolidWorks零件生成器.exe"
```

（改成控制台模式才能看到输出，或用 `python src\app.py` 直接跑）

### Q: 提示「无法加载 SolidWorks COM 绑定」

说明找不到 `sldworks.tlb`。确认：

1. SolidWorks 已安装（不是绿色版/便携版）
2. 在管理员命令行执行一次：
   ```cmd
   "C:\Program Files (x86)\Common Files\SolidWorks Shared\Service\SolidWorksLicensing.exe" /register
   ```

### Q: 建模成功但模型不对

AI 对零件理解有偏差。可以：

- 在文字描述里补充更多尺寸细节
- 用更清晰的图片
- 换一种描述方式重试

### Q: 提示 API Key 无效

1. 去 [platform.deepseek.com](https://platform.deepseek.com) 确认 Key 是否有效
2. 检查账户余额
3. 确认 Key 前后没有多余空格

### Q: 模型保存到哪里了？

点完成后的「**打开所在文件夹**」按钮，或直接去 `C:\Users\<你的用户名>\Downloads`。

文件名格式：`零件中文名_英文名.SLDPRT`

## 🔒 转发给别人安全吗？

**安全。你的 API Key 不在这个文件夹里。**

Key 存在你自己电脑的：

`
C:\Users\<你的用户名>\AppData\Roaming\SolidWorksPartGen\config.json
`

别人拿到 D:\New Program 文件夹时，他们电脑上**没有**这个文件，
所以程序对他们是全新的空配置 —— 他们需要自己填 Key。

**转发前自检**（一条命令确认）：

`powershell
python check_no_keys.py
`

它会扫描所有文件（包括 33MB 的 exe 二进制），用你真实 Key 的前 12 位去匹配，
输出每个文件的结果。最后会告诉你能否放心转发。

> ⚠️ 唯一要注意的：**不要单独发送 %APPDATA%\SolidWorksPartGen\config.json**。
> 那个文件里有明文 Key。但它不在项目文件夹里，正常转发不会带上。

完整说明见 [安全说明-API-KEY.md](安全说明-API-KEY.md)。
